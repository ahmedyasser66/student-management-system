# نظام إدارة وتحليل نتائج الطلاب



محرك لإدارة وتحليل نتائج الطلاب مبني بـ **JavaScript**، يدمج مفاهيم البرمجة كائنية التوجه (Classes & Objects) مع دوال المصفوفات الحديثة (`map` و`filter` و`reduce`) لتطبيق قواعد العمل الأكاديمية، مع واجهة **Bootstrap** تعرض النتائج ومخرجات الـ Console.

## المميزات

- كلاس `Student` يحسب المتوسط والتقدير والنتيجة النهائية لكل طالب.
- **لجنة الرأفة:** استخراج الطلاب المتعثرين (متوسط من 40 إلى 49) وإضافة 5 درجات لمتوسطهم.
- **درع حماية** يمنع القسمة على صفر عند عدم وجود طلاب متعثرين.
- لوحة عرض كاملة:
  - كروت إحصائيات (عدد الطلاب، الناجحين، من يحتاج مراجعة، متوسط الدفعة).
  - جدول للطلاب مع أزرار فلترة (الكل / ناجح / يحتاج مراجعة).
  - رسم بياني يقارن متوسطات الطلاب.
  - شاشة Console داخل الصفحة بتلوين للمخرجات، مع أزرار إعادة التشغيل والنسخ والمسح.
- كود منظم (Clean Code): ثوابت واضحة، ودوال صغيرة لكل منها مهمة واحدة، وفصل بين المنطق والطباعة.

## القواعد الأكاديمية

**التقدير بالحروف (حسب المتوسط):**

| المتوسط | التقدير |
|:---:|:---:|
| 90 فأكثر | A |
| 80 – 89 | B |
| 70 – 79 | C |
| 60 – 69 | D |
| 50 – 59 | E |
| أقل من 50 | F |

**النتيجة النهائية:** يكون الطالب **ناجحاً** فقط إذا تحقق الشرطان معاً:

- المتوسط **50 فأكثر**
- نسبة الحضور **75 فأكثر**

وإلا تكون النتيجة **"يحتاج مراجعة"**.

**لجنة الرأفة:** تشمل الطلاب الذين متوسطهم من **40 إلى 49**، ويُضاف لمتوسطهم **5 درجات**.

## طريقة التشغيل

### من المتصفح (موصى بها)

1. حمّل المشروع أو انسخه:
   ```bash
   git clone https://github.com/USERNAME/student-management-system.git
   ```
2. تأكد أن `index.html` و`index.js` في نفس المجلد.
3. افتح `index.html` في المتصفح (يفضل عبر إضافة **Live Server** في VS Code).
4. اضغط `F12` ثم تبويب **Console** لمشاهدة المخرجات.

> الواجهة تحتاج اتصالاً بالإنترنت لتحميل Bootstrap وChart.js والخطوط.

### من الـ Terminal (Node.js)

```bash
node index.js
```

## شرح الكود

### الكلاس `Student`

| الدالة | الوظيفة |
|---|---|
| `constructor(id, name, grades, attendance)` | تخزين بيانات الطالب |
| `calculateAverage()` | حساب المتوسط باستخدام `reduce` |
| `getGrade(average)` | إرجاع التقدير بالحروف باستخدام `if / else` |
| `getFinalResult()` | تحديد النتيجة النهائية باستخدام `&&` |

### لجنة الرأفة

| الدالة | الأسلوب المستخدم |
|---|---|
| `findStrugglingStudents` | `filter` لاستخراج المتعثرين |
| `applyLeniency` | `map` لإضافة 5 درجات |
| `sumNewAverages` | `reduce` لجمع المتوسطات الجديدة |
| `calculateLeniencyAverage` | حساب المتوسط العام مع درع الحماية |

### الثوابت

```javascript
const PASS_AVERAGE = 50;
const MIN_ATTENDANCE = 75;
const STRUGGLING_MIN_AVERAGE = 40;
const STRUGGLING_MAX_AVERAGE = 49;
const LENIENCY_BONUS = 5;
```

لتغيير أي قاعدة أكاديمية يكفي تعديل الثابت الخاص بها في مكان واحد.
